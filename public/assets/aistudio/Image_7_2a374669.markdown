## Brand & Style

This design system establishes an editorial creative-coding environment for high-craft web animation engineers and digital artists. The aesthetic balances the tactile discipline of traditional printmaking studios with the analytical rigor of developer toolchains. 

### Core Ethos
- **Tactile Paper Meets Technical Rigor**: High-precision parameters, bezier handles, and telemetry monitors live inside an editorial grid structured by fine ink lines, warm parchment layers, and purposeful micro-interactions.
- **Instrumental Focus**: Chrome never competes with the canvas. Controls emulate vintage optical bench equipment and studio drafting boards—calibrated, responsive, and functional.
- **Dynamic Chromatic Energy**: Subdued substrate layers allow saturated pigment accents to guide eye movement, signal keyframe states, and highlight procedural math outputs without visual exhaustion.

## Colors

The palette establishes an analog studio foundation overlaid with functional digital pigments.

### Foundations & Substrates
- **Parchment Surface (`#F9F6F0`)**: Base background simulating unbleached archival paper.
- **Warm Sand Layer (`#EFE9DE`)**: Recessed canvas areas, control well insets, and passive panels.
- **Studio Cardboard (`#E2DACB`)**: Hover states, micro-panel borders, and structural splitters.
- **Chalkboard Dark (`#121316`)**: Full dark-mode inversion, inspector consoles, and code editor viewports.
- **Charcoal Ink (`#1A1A1E`)**: Primary reading typography, crisp iconography, and high-emphasis boundaries.
- **Crisp Ink (`#0F0F12`)**: Deepest contrast line work, high-contrast toggles, and terminal headers.

### Chromatic Pigments
- **Origami Coral (`#FF5A43`)**: Primary interactive focal points, active timeline playback heads, keyframe nodes, and record states.
- **Cyan Pigment (`#00C2D1`)**: Secondary accent, velocity curves, vector motion paths, and active inspector handles.
- **Studio Yellow (`#FFC83B`)**: Warning indicators, performance throttling notices, and tween interpolation states.
- **Crayon Lavender (`#8E7CFF`)**: Physics spring curves, tertiary easing functions, and documentation highlights.
- **Mint Foliage (`#2ECC71`)**: Compiled successfully states, 60fps indicators, and optimized frame passes.

## Typography

The typographic hierarchy utilizes three specialized typefaces working in tandem:

- **Space Grotesk (Display & Section Titles)**: Delivers structural rhythm with humanized geometric quirks. Display weights anchor hero views and experimental lab showcases.
- **Hanken Grotesk (Interface & Editorial Reading)**: High-legibility grotesque engineered for neutral dense copy, settings dialogs, and instructional guidelines.
- **JetBrains Mono (Telemetry, Syntax, & Coordinates)**: Provides unambiguous character distinction for floating point coordinates, cubic-bezier values, code editor tabs, and mechanical control readouts. All tabular data and numeric sliders lock to this family.

## Layout & Spacing

Layouts rely on an asymmetric drafting-board structure designed to scale from compact touchscreens to high-density multi-display setups.

### Grid & Layout Rules
- **Desktop (1024px+)**: 12-column layout split into fixed-width tool rails (280px–360px) and a flex center work surface for the stage canvas. Gutter spaces lock to `1.5rem` (`gutter-desktop`).
- **Tablet (768px - 1023px)**: 8-column layout. Control drawers collapse into bottom sliding sheets with pinned parameter scrubbing.
- **Mobile (< 768px)**: 4-column layout. Margin compresses to `1rem`. Floating canvas occupies the upper viewport half; tabbed micro-controls occupy the lower viewport half. Touch targets maintain a minimum 44px hit-box via invisible bounding padding while keeping visual chrome compact.

## Elevation & Depth

This system avoids blurred realistic drop-shadows. Depth is derived strictly from architectural drafting mechanics:

- **Low-Contrast Structural Borders**: Panels, inspectors, and tool strips sit on 1px solid borders (`#1A1A1E` at 12% to 20% opacity on light surfaces; `#FFFFFF` at 10% on chalkboard dark surfaces).
- **Physical Hard Drop Offsets**: Elevated floating elements (such as timeline drag handles, floating transport controls, and contextual menus) utilize solid, unblurred 2px or 4px offsets in charcoal (`#1A1A1E`), emulating precision laser-cut layered cardboard plates.
- **Surface Layer Stacking**:
  - `Level 0 (Floor)`: `#F9F6F0` (Archival parchment stage)
  - `Level 1 (Panels & Trays)`: `#EFE9DE` (Recessed instrument trays)
  - `Level 2 (Active Cards & Floating Menus)`: `#FFFFFF` with 1px border and 2px `#1A1A1E` solid hard offset
  - `Level 3 (Dark Code Matrix)`: `#121316` high-contrast terminal overlay

## Shapes

The design system employs a restrained `Soft (1)` corner radius (4px standard base) across controls and panels. 

- Interactive buttons, numerical input badges, and segmented tab pills use standard `4px` radii (`roundedness: 1`), conveying a calibrated instrument aesthetic.
- Floating modal sheets and contextual drawer dialogs use `8px` (`rounded-lg`).
- Drag scrubbers, timeline playhead indicators, and keyframe points retain precise geometric silhouettes: pure diamonds (45° rotated squares) or sharp circular control beads (50% radius) sized strictly to 8px–12px bounds.

## Components

### Buttons & Transport Controls
- **Primary Action (Record / Run / Export)**: Background filled with Origami Coral (`#FF5A43`), label text in `#FFFFFF`, framed with 1px `#1A1A1E`. On press: 1px diagonal translate down-right to simulate mechanical actuation.
- **Secondary Action**: Background `#EFE9DE`, crisp 1px `#1A1A1E` border, text in `#1A1A1E`. Hover triggers a tint shift to `#E2DACB`.
- **Ghost Utility**: Transparent substrate, monospaced label with bracketed frame accents (`[ Reset ]`), active color shifts to Cyan Pigment (`#00C2D1`).

### Form Inputs & Scrubbers
- **Numeric Control Sliders**: Integrated input box containing a JetBrains Mono numeric readout paired with an interactive scrub lane. The filled track uses Cyan Pigment (`#00C2D1`), while the unfilled track shows a dotted or low-opacity neutral line. Touch dragging initiates an overlay magnified value pill.
- **Code Inspector Tabs**: Monospaced folder-tab styling. Inactive tabs render on `#EFE9DE` with muted gray text. Active tab locks to Charcoal Ink (`#1A1A1E`) with high-contrast text and a top accent stroke of Origami Coral (`#FF5A43`).

### Selection Controls (Checkboxes, Toggles, Radio)
- **Checkboxes**: 14px square, 2px rounded corners, 1px solid border. Checked state fills with Crisp Ink (`#0F0F12`) featuring a stark white geometric checkmark.
- **Toggles (Switches)**: Compact rectangular track (28px × 16px) with an interior sliding square pip (10px × 10px). Active state illuminates track in Mint Foliage (`#2ECC71`).

### Cards & Lab Modules
- Base module constructed with 1px solid `#1A1A1E` border over `#FFFFFF` or `#F9F6F0`. Header strip contains section classification formatted in `label-code-caps` (`JetBrains Mono`, 11px uppercase, tracking `0.08em`) with an option for an FPS frame-counter badge.

### Interactive Canvas Zone
- Framed by a subtle dotted grid matrix (`#1A1A1E` at 6% opacity) with coordinate ticks at the four inner corners. Dynamic overlay handles for velocity curves render in Coral and Cyan vectors with 2px draggable control nodes.
